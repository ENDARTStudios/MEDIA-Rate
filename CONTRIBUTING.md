# Contribuindo para o MEDIA Rate

O fluxo de contribuição (issues, branches, PRs, convenções) está documentado em
[`docs/WORKFLOW_GITHUB.md`](docs/WORKFLOW_GITHUB.md). Resumo:

1. **Issue primeiro** — toda mudança corresponde a uma Issue no GitHub.
2. **Branch** `feature/<tarefa-id>` a partir de `main`.
3. **PR** com `Closes #<n>` no corpo e o checklist do
   [PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md).
4. **CI verde + review** antes do merge em `main`.
5. **Commit convencional** — `feat|fix|chore|docs|refactor|perf|security(scope)`.

Para contexto do domínio, arquitetura e decisões, veja `PLANO_MESTRE.md`,
`DECISOES.md` e `HANDOFF.md` na raiz.
